## Project Overview
**Intelligent-Codelabs** is an interactive coding sandbox ecosystem powered by AI, designed to act as a personal programming mentor. This platform was born to solve the modern **AI Dependency** phenomenon, where beginer developers frequently get stuck in a copy-paste cycle using generic generative AI's without actualy understanding the underlying logic.

at Intelligent-Codelabs, the AI doesn't spoon-feed you with instant aswer. Instead, it acts as a critical facilitator that evaluates logical errors, analyzes bugs, and provides interactive guidance to push you to think critically and truly master the code you write.

---
##  Real-World Problem Space
* **The "AI Copy-Paste" Trap:** Beginners often generate whole blocks of code without understanding the core fundamentals, leading to a new type of *Tutorial Hell* where the app runs, but their logical comprehension remains at zero.
* **Fragmented Learning Materials:** Programming roadmaps on the internet are often disorganized, overwhelming, and lack a proper step-by-step progression.
* **Financial Barriers:** Premium interactive coding platforms often charge expensive subscription fees, creating an unfair barrier for students and independent learners.

---

##  Core Features
* **Instant AI Evaluator & Logic Mentor:** Powered by an intelligent AI Engine (Gemini API) to check code optimizations, logical soundness, and edge-case bug fixing without exposing direct solutions.
* **Massive Multi-Language Dropdown (20+ Techs):** Seamless click-based navigation from the Navbar to access 20+ programming languages and popular frameworks (JavaScript, TypeScript, Python, Go, Rust, C++, Java, SQL, React, Next.js, Laravel, and more) directly from your browser with zero local setup.
* **Structured Curriculum Roadmaps:** Fixed modular learning paths that guide users step-by-step through clear syllabus stages: Easy, Medium, and Hard.
* **Premium Monaco Sandbox IDE:** Integrates an industry-standard browser editor interface mimicking the true look and feel of Visual Studio Code.
* **Seamless Google Authentication:** One-click instant login via Google OAuth to keep your learning progress completely persistent and securely synced in the cloud.
* **Dual Theme Switcher:** Global dynamic toggle between a premium futuristic *Dark Mode* with elegant text shimmer effects and a crisp, clean *Minimalist Light Mode*.

## Tech Stack
### Front-End:
* **React.js (Vite) / Next.js** — Core UI architecture.
* **Tailwind CSS** — Utility-first design for premium dark and light layouts.
* **Framer Motion** — Responsive scroll fade-ins and interactive button micro-animations.
* **@monaco-editor/react** — Interactive in-browser compiler & editor sandbox.

### Back-End & AI:
* **Node.js / Express.js** — Robust API Gateway.
* **Gemini AI API** — Core AI engine for intelligent code assessment.
* **Firebase Auth / NextAuth.js** — Google OAuth layer.
